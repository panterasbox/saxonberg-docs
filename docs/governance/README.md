# Governance instruments

Normative governance **instruments** for the Compact — the
documents that *bind*, as distinct from the design slates that *explore*.
These are not backlog (they don't live under `docs/slates/`); they're the
constitutional texts the cooperative build
produces and references.

- [draft-constitution.md](./draft-constitution.md) — the bare-bones
  **kernel** that ships to every community: a three-floor test
  (firewall / machine / deferred), rights-as-bindings-on-tools, treated
  as code with a config block (the Schedule of Parameters). *Draft, not
  ratified.*
- [founding-charter.md](./founding-charter.md) — the founder's
  **self-binding commitment**, in force from the first dollar (the
  instance-specific instrument Art. XI's founding-stake bound requires).
  Binding by code + publication + exit, not law.

The open-ended governance *design* lives in
cooperative-slate.md and
amendment-library-slate.md
(the model-amendment library layered on the kernel).
